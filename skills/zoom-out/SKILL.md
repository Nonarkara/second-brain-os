# Zoom Out

I don't know this area well enough. Go up a layer of abstraction.

Give me:
1. A map of all relevant modules and their relationships
2. Who calls this, what it calls, what depends on it
3. The domain vocabulary this code uses — not just variable names, the concepts
4. What breaks if I touch this wrong

Use the project's own naming conventions. Don't invent new abstractions.

Stop when I understand where this fits in the whole.
